# Planning UI – Custom Scheduler + Grid

Dit project bevat een maatwerk user interface met:

- 📅 Een interactieve scheduler met statusoverzicht per dag
- 📊 Een data grid met nested tabellen en togglebare orderinformatie
- 🔄 Dynamische filtering en datumselectie
- 💡 Ontworpen voor gebruik in kantooromgevingen (niet mobielgericht)
- 🎨 Volledig los van Kendo UI, geschreven in HTML/CSS/JS

## Projectstructuur

```
/
├── index.html
├── /css/
│   ├── layout.css
│   ├── grid.css
│   └── scheduler.css
├── /js/
│   ├── main.js
│   ├── grid.js
│   └── scheduler.js
├── /data/
│   └── orders.json
└── .gitignore
```

## Instructies

1. Clone de repository
2. Start een lokale webserver (zoals Live Server in VS Code)
3. Pas `orders.json` aan om testdata te gebruiken
4. Bouw verder met tabbladen, exports of thema-aanpassingen
